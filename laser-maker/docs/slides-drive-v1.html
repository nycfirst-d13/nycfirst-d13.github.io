No logins

One shared class PIN typed once per session. The browser caches it in localStorage (laserMakerDrivePin) — returning students skip the prompt. No Google accounts, no OAuth, no student credentials to manage.

Instant upload

Click "Save to Cloud," enter Design Name + Project. A fetch POST sends the PIN, SVG, and slugified filename to a Google Apps Script. The script validates the PIN, finds or creates today's date subfolder, and saves the file. Green toast: Saved to Drive · filename.

One shared folder

Designs land in a date subfolder inside "Laser Maker Exports" — automatically organized by class session. Files are dimensioned in real inches, ready for Illustrator and the laser. Re-exports stack alongside rather than overwrite.

Admin Setup

One-Time Setup

Done once by a teacher or IT admin — takes about 10 minutes.

01
Create the Drive folder

In Google Drive, create a folder called "Laser Maker Exports". Open it and copy the folder ID from the URL — it's the string after /folders/.

02
Create an Apps Script project

Go to script.google.com, create a new project, and paste the contents of docs/apps-script-uploader.js from this repo.

03
Set Script Properties

Project Settings → Script Properties: add DRIVE_PIN and ROOT_FOLDER_ID.

04
Deploy as Web App

Deploy → New Deployment → Web App → Execute as: Me → Who has access: Anyone. Copy the /exec URL.

05
Paste URL into the app

In modules/drive-upload.js, set DRIVE_UPLOAD_URL to the deployed URL. Done — commit and push.

What the Script does

Reads DRIVE_PIN from Script Properties, compares — never in source code

Finds or creates today's date subfolder (US Eastern) inside Exports

Writes SVG as plain text — duplicates stack, never overwrite

Returns {"ok":true} — app caches PIN, shows green toast

Authentication

The PIN System

Shared class PIN

One PIN per class — shared verbally or on the board before class starts. Students type it once per session in the PIN dialog that appears when they click "Save to Cloud."

localStorage key: laserMakerDrivePin — cached per device

Never in app source code — server side only (Script Properties)

Auto-invalidated on all devices when the PIN rotates

Rotate anytime

Change only the DRIVE_PIN Script Property. No redeploy needed. All cached PINs on student devices are rejected on their next export and they'll be prompted for the new one.

How to rotate
Apps Script → Settings
→ Script Properties
→ Edit DRIVE_PIN
→ Save
Resilient design

If Drive is unreachable, the SVG downloads locally as a fallback. Students never lose work — the local file is always the safety net.

Wrong PIN → dialog shakes, inline error, clears cached copy

No lockout — re-enter correct PIN, upload retries automatically

Network fail → SVG downloads locally, file never lost
