Save to Cloud · Google Drive
Feature Overview

What is Save to Cloud?

A built-in button that sends the student's SVG to a shared Google Drive folder — no accounts, no email, no USB drives.

No logins

One shared class PIN typed once per session. No Google accounts, no OAuth, no student credentials to manage.

Instant upload

Click "Save to Cloud," name the file, and it's in Google Drive within seconds. A green toast confirms with the filename.

One shared folder

All class designs land in "Laser Maker Exports/" — easy to find, sort, and open in Illustrator for the laser.

Student Workflow

The Process — 5 Steps

1
Open Browser

Navigate to the Laser Maker URL on any classroom computer or Chromebook.

2
Design Parts

Use shapes, pen tool, text. Assign process types: main cut, fold, etch, free.

3
Name & Export

Click "Export SVG," give it a clear name. File is ready to upload.

4
Save to Cloud

Click the button, enter the class PIN. Green toast confirms upload.

5
Done — In Drive

File is in "Laser Maker Exports/" — teacher opens Drive to collect.

For Teachers

Teacher Workflow

During Class
1

Students design and export their SVG in Laser Maker.

2

Students click "Save to Cloud" and enter the class PIN.

3

Green toast confirms — no teacher action needed per student.

4

Share the PIN verbally or written on the board before class.

5

Open Google Drive → "Laser Maker Exports/" to see all files.

Sending to Laser

After class, collect files from Google Drive. Open each SVG in Adobe Illustrator. Use File → Print → Epilog Fusion Job Manager to send to the cutter.

The process colors (blue / red / green / black) map directly to Epilog driver settings — no reassignment needed.

Drive → Illustrator → File → Print → Job Manager
Admin Setup

One-Time Setup

Done once by a teacher or IT admin — takes about 10 minutes.

01
Create the Drive folder

Create "Laser Maker Exports/" in a shared Google Drive accessible to all staff who print to the laser.

02
Add the Apps Script

Open Google Apps Script, paste the uploader code, save it inside the shared Drive.

03
Set Script Properties

Apps Script → Settings → Script Properties: add DRIVE_PIN and ROOT_FOLDER_ID.

04
Deploy as Web App

Deploy → New Deployment → Web App → "Anyone" access. Copy the deployment URL.

05
Wire URL into Laser Maker

Paste the deployment URL into drive-upload.js and re-serve. Done.

Authentication

The PIN System

Shared Class PIN

One PIN per class — shared verbally or on the board. The browser caches it locally after first entry. No individual accounts.

Rotate Anytime

Update DRIVE_PIN in Script Properties — takes effect immediately, no redeploy needed.

No Lockout

Wrong PIN shows an error but never blocks. Offline? The export downloads locally as a fallback — the workflow continues.
